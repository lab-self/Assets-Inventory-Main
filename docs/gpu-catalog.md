# GPU catalog

The Peripherals dropdown includes common NVIDIA GeForce/RTX/Quadro, AMD
Radeon/Radeon PRO, Intel Arc/integrated, and Apple integrated GPU names.
It is a curated catalog, not an exhaustive list of every historical, OEM,
laptop or future GPU. Use **Other / unlisted model** to preserve the exact
manufacturer model name for those devices. Graphics memory is entered
separately because memory configurations vary by device. Leave it blank for
shared or unknown memory; GB and TB inputs persist in GB without rounding.
